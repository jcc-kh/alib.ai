Phone records (messages, calls, locations, transactions, device events), each with its source file, line and raw JSON. Checks read through views that apply each phone's clock offset and leave out rows the investigator disputed. A dispute reruns every check that cited the row.
tool calls: targeted checks, apply_verdict_rule, get_reliability · JSON + evidence ids back
Checks never conclude. They return rows and numbers. Discovery never decides. It finds leads; a check makes them evidence. Agents never compute. They route, follow up and write one sentence per finding.
