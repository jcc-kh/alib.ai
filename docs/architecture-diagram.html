Facts come from code. Checks are pure Python over the store; every number is computed there and returned with the rows used.
The model routes and phrases. It splits briefs, picks checks, and writes one sentence; it never does arithmetic or reads raw data directly.
Every claim is traceable. Statement → number trace → check output → evidence ids → row → file, line and raw JSON in the bundle.
Anyone can re-check. The Verify tab recomputes from raw rows without trusting the check; a mismatch means don't rely on it.
