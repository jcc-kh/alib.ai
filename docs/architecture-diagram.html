Evidence (+ gap view)How we knowVerify · recomputeSources · file + line
Checks never conclude. One fixed question each, JSON out with the row ids used. Every number in the report is computed here.
Agents never compute. They choose checks and parameters, follow up, read message content, merge, dismiss with a reason, and word.
Gaps are not guilt. Missing location is "no location data". Only location_off (phone in use during the gap) is raised by default.
Everything is traceable. Statement → number trace → signal → evidence ids → row → file, line, raw JSON. Verify recomputes it in the browser.
