# MSAB 2026 Digital Summit CTF

Built by Hexordia for MSAB, the company behind the XRY forensic tool. It is not a Cellebrite dataset.

**Status: both phones downloaded, every database extracted and listed.** Everything on this page was read from the files unless it says otherwise.

- Full table and column listings: [iPhone 12](schemas/msab-2026-iphone12.md), [Samsung S20](schemas/msab-2026-samsungs20.md)
- All data is fictional.

### How to get them

```bash
cd data/scripts && pip install -r requirements.txt

# iPhone: every database, about 560 MB, a few minutes. Use --preset ios for the 100 MB core set.
python fetch_from_remote_zip.py https://msab26.hexordiactf.com/iPhone12.zip \
    --inner iPhone12FFS.zip --preset ios-all --out ../raw/msab-2026/iphone12

# Samsung: the phone copy is compressed inside the outer zip, so download that one entry (9 GB)
python fetch_zip_entry.py https://msab26.hexordiactf.com/SamsungS20.zip \
    SamsungS20FFS.zip ../raw/msab-2026/samsungs20/SamsungS20FFS.zip
python extract_dbs_from_zip.py ../raw/msab-2026/samsungs20/SamsungS20FFS.zip \
    ../raw/msab-2026/samsungs20/extracted

# Regenerate the schema listings
python dump_schema.py ../raw/msab-2026/iphone12 > ../datasets/schemas/msab-2026-iphone12.md
python dump_schema.py ../raw/msab-2026/samsungs20/extracted > ../datasets/schemas/msab-2026-samsungs20.md
```

The Samsung download took about 7 minutes on a fast connection.

## Fit for Alib.ai

| Check | Verdict |
|---|---|
| `missing_messages` | **Works.** Texts are on both phones today. Signal and Instagram are readable on Emily's phone; Blaise's copies need decrypting or blob parsing |
| Alias and contact checks | **Works.** Contacts and account names are readable on both |
| `distance_between`, `silent_meetings` | **Weak.** No GPS track on the iPhone; the Samsung is unchecked |
| `money_chains` | **Nothing to run on.** Wallet balances exist, but no transfers between the two people |
| `synchronised_behaviour` | **Possible.** Needs the iPhone's Biome files and the Samsung's `usagestats` parsed |

**Strengths:** two phones from people who talk across texts, Signal and Instagram; hidden identities and a secure folder on Emily's side; a complete answer key; cheap to fetch; every database already listed.

**Weaknesses:** one pair of people only; small message volumes (tens, not thousands); no money trail; weak location.
